Automation

Create optimization tasks with specific targets (albums, folders, date ranges) and quality settings. Tasks can run manually, on a schedule (daily, weekly, monthly), or be triggered from Apple Shortcuts for integration with iOS and macOS automation.

On macOS, you can flag a local folder task as "watched." Sami monitors the folder (and subfolders) for added or modified files using macOS file system events, with a debounce you can tune per-task so a large import doesn't trigger back-to-back runs. When changes settle, Sami runs the task automatically. iOS doesn't allow background watchers on arbitrary folders, so this feature is macOS-only.

Yes, on macOS. Enable "Keep running when window is closed" in Settings and Sami stays alive so watched folders and scheduled automations keep firing. You can independently control whether Sami appears in the Dock, the menu bar, both, or neither — opt into fully invisible background execution if that's your preference. Relaunching from Finder/Spotlight reactivates the running process and brings the window back.

No. Sami detects when a folder is on a network volume, SMB share, or File Provider extension (iCloud Drive, Dropbox, Box, etc.) and throttles both reads and backup writes — chunked transfers with short pauses between chunks — so your link stays usable for everything else. Local internal SSDs still run at full speed. You can adjust the network concurrency cap per task.

Sami materializes dataless File Provider items before reading them, using the system's download coordination APIs. After a successful optimization it can evict the local cached copy on iCloud Drive so your disk stays clean (best-effort on third-party providers, which don't all expose the same eviction surface).
