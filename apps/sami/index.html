Pick What You Optimize

Every task preview lets you enter Select mode and choose exactly which items to run. Sami processes only what you picked — never quietly pulls in newly-matching media behind your back.

📡

Network-Friendly Throttling

Sami detects when a folder lives on a NAS, SMB share, or cloud drive and throttles reads and backup writes so your link never saturates. Local SSDs still run at full speed.

☁️

iCloud Drive & File Provider Ready

Works with dataless files from iCloud Drive, Dropbox, Box, and other File Provider extensions. Sami materializes items before read and can evict the local cache after a successful run.

👁️

Watched Folders (macOS)

Flag any folder as a watched source and Sami re-runs the task automatically whenever files are added or modified, with a configurable debounce so a big import doesn't thrash.

📊

Live Activity Feed

Watch successes, skips, and failures scroll by in real time as a run progresses — with the reason next to each item — so you can spot patterns without waiting for the summary.

🌊

Menu Bar Presence

On macOS, Sami lives in the menu bar with a pulsing shark icon while a task is running. Pause, resume, or cancel right from the popover. Hide the Dock icon for an invisible background helper if you prefer.

💽

Robust on Any Drive

Atomic, volume-local writes mean optimizations on external SSDs and network-mounted volumes don't leave partial files or corrupt data, even if something is yanked mid-run.

⏱️

No Minimum Age Option

Don't want to wait a week before Sami touches a photo? Pick "No Minimum" and optimize everything that matches your filters, including files you just saved.

🗂️

Per-Task Backup Folders

Every task picks its own backup destination. Different tasks can back up to different drives — external SSD for videos, a NAS for photos, or nothing at all. No more global folder everything has to share.

🛑

Smart Run Conditions

Sami pauses automatically in Low Power Mode, on battery, on metered networks, or in Low Data Mode — each gate is an independent toggle. Folder tasks over a hotspot or a NAS with a capped plan just stop until conditions change.

🎚️

Adjustable Resource Usage

Low / Normal / Maximum CPU throttling plus a configurable concurrency cap. Low mode runs Sami at reduced process priority with longer pauses between files so your foreground apps stay responsive — great for daytime batches.

⚠️ Important: Lossy Compression

Sami uses lossy compression to achieve significant space savings. This means there will be some quality loss in the optimized media. The side-by-side preview lets you evaluate if the quality trade-off is acceptable for your needs. Always keep backups of important media before optimization.
