Enter Space Light

The core of Enter Space for Windows, Linux and Android. Use Google Drive, Dropbox, OneDrive, S3, your NAS and more as drives, and back them up or keep them in sync.

Download View the source on GitHub

What it does

It is built on rclone, with a tray icon and a small settings window on desktop. Your files stay in the apps you already use.

  • 💾

    Cloud storage as a drive

    A drive letter in File Explorer on Windows, a folder on Linux, and a location in the Files app on Android.

  • 🔁

    Backups and syncs

    Copy, mirror, move or two-way. Run them on a schedule or at sign-in; on Windows and Linux, also when a chosen USB drive is plugged in.

  • 🕰️

    Time Portal

    Browse a backup as it was at any earlier run, then restore files or whole folders.

  • 🛡️

    Safer by default

    Backups keep old versions, and a delete guard stops a run that would delete more than a quarter of the backup.

  • ⚙️

    Tuned for you

    Caching, retries and rate limits are set for each provider. Your own advanced settings still win.

  • 🧰

    Your rclone.conf

    It uses rclone’s standard config file, so remotes you already set up are there. A command line is included on Windows and Linux.

Download

Every build comes from GitHub Releases, not from an app store. Open the latest release and pick the file for your system.

Windows 10 and 11

x64 and Arm. Run the installer, or use the portable zip. Drive letters need the free WinFsp driver, which the installer adds if it is missing.

Get it for Windows

Linux

x86_64 and arm64, as .deb, .rpm or .tar.gz. The tarball installs without root and needs FUSE 3.

Get it for Linux

Android 8.0 and later

An arm64 APK you install yourself. The Android version is new: it has been tested on an emulator, not yet widely on real phones.

Get the APK

On Android, drives show up in the Files app and in file pickers. Apps that only open ordinary file paths can’t see them.

Before you install

These builds are distributed outside the app stores, so your system may ask you to confirm.

Windows: the builds aren’t code-signed yet, so SmartScreen may warn you. Check your download against the SHA256SUMS file in the release, then choose “More info” and “Run anyway”.

Android: it isn’t on Google Play, so Android asks you to allow installs from your browser or file app. The APK is signed with the project’s own key, and the README lists its fingerprint. The app doesn’t check for updates, so install new versions the same way.

Linux: install the package or run the tarball’s install script. The install guide on GitHub has the commands.

Code signing policy: free code signing provided by SignPath.io, certificate by SignPath Foundation. The application is in progress, and releases so far are not signed. Read the code signing policy and the privacy policy.

On an Apple device?

Enter Space is the full app for iPhone, iPad, Mac and Apple TV, with photo, video and music libraries and Files and Finder integration. Enter Space Light is its smaller, free sibling, and backups made by the Apple app can be browsed and restored in it.
