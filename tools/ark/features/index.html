ARK

Meet the crew

Seven tools, one skeleton. Each is a small command-line program with the same layout and a guided setup, so learning one is learning all of them.

🦝Rocket

Ships to the App Store, Google Play and the Microsoft Store.

Private, open-sourcing planned

  • 🚀

    One release command

    Drafts the version on every platform, pushes the listing, uploads the build and frames the screenshots, then stops before submit so QA comes first.

  • 🏪

    Three stores, one listing

    One metadata file feeds all three stores, trimmed to each store's limits. Google Play gets tracks and staged rollouts.

  • ✅

    Careful submits

    Waits until the newest build has really finished processing, attaches it and submits it for review, and refuses anything that would stall the release.

  • 🎮

    Game Center and pricing

    Keeps leaderboards, achievements, prices and availability in step with files in the repo.

  • 📱

    QA from your phone

    A checklist board you work through on your phone. A green board unlocks the submit button.

🦉Soren

Cross-platform QA that gates every release.

Private, open-sourcing planned

  • 🧪

    Every suite, one board

    Runs Xcode simulator tests, Rust, Gradle unit and device tests, Node checks or any command, and sums them up on one pass/fail board.

  • 🚦

    A gate, not a report

    Exits non-zero on any failure, so a release script, an agent or a CI job stops on red.

  • 🔌

    Fits any project

    One config file lives with each project. The tool itself knows nothing about any app.

  • 📄

    Ready for CI

    Writes JUnit and JSON results and a step summary for continuous integration.

🦊Knox

AI security audits, on command.

Private, open-sourcing planned

  • 🗺️

    Threat model first

    Every audit follows the same fixed method, from attacker capabilities through authentication, cryptography and injection to the supply chain.

  • 📊

    Structured findings

    Each finding has a severity, a location, an attack scenario and a specific fix, in a dated report.

  • 📈

    Posture diffs

    Compares two audits: what's new, what was fixed and what persists. A new critical or high finding fails the gate.

  • 🧠

    Honest about limits

    Knox raises the floor on every release. Novel cryptography is flagged for specialist review, never certified.

🐵Monkr

Screenshot framing and animation.

Free and open source

  • 📱

    Real device frames

    Pixel-true frames for iPhone, iPad, Mac, Apple Watch, Apple TV and more, in every color.

  • 🖼️

    Store-ready sets

    Canvas presets for every App Store and Google Play size, with headlines and backgrounds.

  • 🎬

    Animation

    Chainable presets turn a layout into a short video, scored by Tom if you like.

  • ⌨️

    Headless rendering

    The same renderer runs from the command line, so fresh captures become framed images without a click.

More about Monkr

🐆Levi

Localization across the Big 8 languages.

Private, open-sourcing planned

  • 🌏

    The Big 8

    Simplified Chinese, Japanese, German, French, Spanish, Korean, Brazilian Portuguese and Italian, on every surface.

  • 🧩

    Every surface

    Xcode String Catalogs, store listings, Android resources and web dictionaries, rewritten byte for byte.

  • 🔎

    Drift tracking

    Knows when the English has moved on, so only stale or missing strings get translated.

  • 🧪

    Compiler-proven audits

    Checks placeholders, lengths and glossary terms, and uses the compiler to find strings the catalog never heard of.

🦎Tom

A music machine for jingles and soundtracks.

Free and open source

  • 🎹

    Melodies in seconds

    Style, key, tempo, swing and shape: dial them in and Tom writes the melody.

  • 🧱

    Songs like Lego

    Snap intro, verse, chorus and ending blocks together, or let Auto build the rest.

  • 📻

    Endless radio

    Pick a station and Tom keeps writing new songs in that style.

  • 🎬

    Scores Monkr's videos

    Monkr asks Tom for a jingle whose final hit lands exactly where the clip needs it.

🐰Hopps

Operational awareness, with a fix button.

New, in development

  • 📊

    What the stores report

    App Store Connect analytics, sales, device mix, ratings, reviews, chart rankings and keyword positions, plus Google Play and Microsoft Store stats and reviews.

  • 🌐

    The website, side by side

    Cloudflare web analytics lined up against store page views.

  • 📣

    Social

    YouTube and Product Hunt, with Instagram and X optional.

  • 🎫

    Support as tickets

    Support emails become tickets, next to the reviews and numbers they relate to.

  • 🛠️

    Fix with Claude

    One tap hands a ticket or suggestion to Claude Code, which drafts the change in an isolated git worktree and runs the tests.

  • 🚥

    Small fixes ship, code waits

    Copy, localization and documentation changes ship on their own. Code changes wait for your approval.

  • 🏠

    Private by design

    Runs as a background service on your Mac, reachable over Tailscale, with no tracking SDKs in any app.

  • AI writes files; only you publish
