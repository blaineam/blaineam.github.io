Edit the site

This page is public, but it can only change anything with a key that GitHub gives to the owner of the repository. There is no server and no password here.

Kept in this browser only, sent only to api.github.com, and never shown again after you press the button.

Which token to create

Open GitHub with the token form filled in

Opens github.com in a new tab (sign in there if asked). Nothing is sent from this page; the link only carries the settings below.

  1. Already filled in by the link: the name (“wemiller.com editor”), the description, the resource owner (blaineam), an expiry of 90 days, and Repository permissions → Contents: “Read and write”. Change the expiry if you like; GitHub adds “Metadata: Read-only” by itself. Leave every other permission alone.
  2. The one thing the link cannot set, so do it by hand: under Repository access choose “Only select repositories” and pick just blaineam/blaineam.github.io.
  3. Press Generate token, copy it, come back to this tab and paste it above. Do this once on each phone or computer.
Doing it without the link

On GitHub open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access: “Only select repositories”, just this repository. Permissions → Repository permissions → Contents: “Read and write”, nothing else. Pick an expiry, generate, paste it above.

Do not use a classic token. A classic token with the “repo” scope can write to every repository you have, and it would be sitting in this browser. The editor refuses them. A fine-grained token limited to this one repository can do nothing else if it ever leaks, and you can delete it on GitHub at any time.

The editor will work on branch main.
